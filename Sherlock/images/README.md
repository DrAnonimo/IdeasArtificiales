# Imágenes Victorianas

Este directorio contiene las imágenes victorianas para ilustrar el juego.

## Imágenes recomendadas

Puedes agregar las siguientes imágenes (opcional):

- `case.jpg` - **IMPORTANTE:** Imagen pre-generada que ilustra el caso/crimen (se muestra siempre al inicio)
- `sherlock.jpg` - Retrato o ilustración de Sherlock Holmes
- `rose.jpg` - Imagen de una camarera o sirvienta victoriana
- `arthur.jpg` - Retrato de un joven caballero victoriano
- `study.jpg` - Biblioteca o estudio victoriano con ambiente misterioso

**Nota:** La imagen `case.jpg` se mostrará siempre al inicio del juego como ilustración del caso. Si no existe, se usará una imagen por defecto desde una URL pública.
