# 🎨 Prompts para Generar Imágenes con IA

Este documento contiene prompts optimizados para generar las imágenes del juego usando herramientas de IA como DALL-E, Midjourney, Stable Diffusion, o similares.

## 🖼️ case.jpg - Imagen Principal del Caso (MÁS IMPORTANTE)

### Prompt Principal:
```
A detailed Victorian era crime scene illustration: A wealthy Victorian library room at night, dim gas lamp lighting. An elegant desk with papers scattered, a dagger visible on the floor. A window slightly ajar letting in cold night air, curtains moving gently. Rich mahogany bookshelves filled with leather-bound books. The room has a locked door visible in the background. Dark, mysterious atmosphere with dramatic shadows. 1890s London setting, realistic style, cinematic lighting, moody and atmospheric. No people visible, focusing on the scene of the crime.
```

### Variaciones alternativas:

**Para DALL-E / ChatGPT:**
```
Victorian crime scene illustration, 1895 London, wealthy gentleman's library at night, gas lamp lighting, dagger on floor, window ajar, scattered papers on desk, dark mysterious atmosphere, dramatic shadows, realistic detailed style
```

**Para Midjourney:**
```
victorian crime scene, 1890s london library, night scene, gas lamp lighting, dagger on floor, window ajar, dark mysterious atmosphere, cinematic lighting, moody shadows, detailed illustration, realistic style, dramatic composition --ar 16:9 --style raw
```

**Para Stable Diffusion:**
```

```

## 💡 Consejos para Mejorar los Resultados

### 1. **Agregar términos de estilo:**
- Agregar `--style raw` o `--stylize X` en Midjourney
- Usar términos como "realistic", "detailed", "high quality", "cinematic lighting"
- Especificar época: "Victorian era", "1890s", "19th century"

### 2. **Para crear variaciones:**
- Cambiar el ángulo: "front view", "side view", "three-quarter view"
- Ajustar iluminación: "dramatic lighting", "soft lighting", "gas lamp lighting", "dim lighting"
- Modificar expresión: "worried expression", "confident expression", "mysterious expression"

### 3. **Para la imagen del caso especialmente:**
- Enfatizar que NO debe haber personas visibles (focus en la escena)
- Mencionar elementos específicos: dagger, window, papers, locked door
- Crear atmósfera misteriosa: "dark", "moody", "atmospheric", "dramatic shadows"

### 4. **Formatos recomendados:**
- Para imágenes de personajes (portraits): proporción 3:4 o 2:3
- Para imagen del caso (escena): proporción 16:9 o 4:3

### 5. **Herramientas recomendadas:**
- **DALL-E 3** (via ChatGPT Plus): Usar los prompts principales tal cual
- **Midjourney**: Usar las variaciones con parámetros `--ar` y `--style`
- **Stable Diffusion**: Usar prompts con muchos detalles descriptivos
- **Bing Image Creator**: Usar prompts simples y directos

---

## 📝 Ejemplo de Uso

1. Elige una herramienta de IA (DALL-E, Midjourney, etc.)
2. Copia el prompt correspondiente a la imagen que necesitas
3. Genera la imagen (puede tomar varios intentos)
4. Descarga la imagen generada
5. Guárdala en `images/` con el nombre correcto:
   - `case.jpg` (más importante)
   - `sherlock.jpg`
   - `rose.jpg`
   - `arthur.jpg`
   - `jenkins.jpg`
   - `study.jpg` (opcional)
